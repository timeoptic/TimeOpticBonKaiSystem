# กรอบใช้สต็อกเดียวกัน: แพไม้ ← บ่อนไก่ (ขึ้น Hostinger Cloud ได้)

Hostinger Cloud ให้ผู้ใช้ฐานข้อมูลหนึ่งคนเข้าได้ฐานเดียว (ตรวจบนเซิร์ฟเวอร์จริงแล้ว 14 พ.ย. 2026)
แบบ "ฐานกลาง stock_shared + view" ที่เคยทำไว้จึงขึ้นไม่ได้ และถูกถอดออกแล้ว

**แบบที่ใช้ตอนนี้**

- แต่ละสาขามีเว็บและฐานของตัวเองฐานเดียว เหมือน Bewell
- สต็อกกรอบจริงอยู่ที่ **บ่อนไก่** ที่เดียว
- แพไม้ค้น ตัด และคืนกรอบผ่าน API ของบ่อนไก่โดยอัตโนมัติ (`api/services/FrameRemote.php`)
- เลนส์ไม่เกี่ยว ยังส่งไปคลัง TimeOptic ตามเดิม

## ตั้งค่า

### 1. บ่อนไก่: สร้างบัญชีเชื่อมต่อ

สร้างบัญชีหนึ่งบัญชีจากหน้าผู้ใช้ เช่น `phaemai.link`:

- ให้บทบาท **stock** อย่างเดียว ซึ่งตัด / คืน / ค้นสินค้าได้ แต่ไม่เห็นต้นทุนและเข้าหน้าร้านไม่ได้
- ตั้งรหัสยาว ๆ และห้ามใช้บัญชีนี้ล็อกอินหน้าเว็บ

### 2. แพไม้: ตั้ง `.env`

เพิ่มใน `.env` ของแพไม้ ส่วนบ่อนไก่ไม่ต้องตั้ง:

```
FRAME_STOCK_URL=https://<โดเมนบ่อนไก่>
FRAME_STOCK_USER=phaemai.link
FRAME_STOCK_PASS=<รหัส>
FRAME_STOCK_TAG=phaemai
FRAME_STOCK_LABEL=บ่อนไก่
FRAME_STOCK_FROM=แพไม้
```

**`FRAME_STOCK_TAG` ห้ามว่างและห้ามซ้ำกับสาขาอื่น** เพราะเลขเคสของสองสาขาซ้ำกันได้ (`CASE-2026-00001` มีทั้งสองที่)
ค่านี้ใช้นำหน้ากุญแจกันตัดซ้ำ (`idem_key`) ไม่ใส่จะไปได้คำตอบของเคสบ่อนไก่กลับมาแทนการตัดจริง

### 3. ฐานข้อมูล: ทำทั้งสองสาขา ครั้งเดียว

`Migrate::run()` เพิ่มให้เองบนเครื่องร้าน ส่วนบนโฮสต์ให้รัน SQL นี้:

```sql
CREATE TABLE IF NOT EXISTS frame_remote_cache (
  sku varchar(100) NOT NULL, search_text varchar(1000) NOT NULL DEFAULT '',
  row_json longtext NOT NULL, seen_at datetime NOT NULL, PRIMARY KEY (sku)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
ALTER TABLE case_stock_issues
  ADD COLUMN remote tinyint(1) NOT NULL DEFAULT 0,
  ADD COLUMN remote_state varchar(12) DEFAULT NULL,
  ADD COLUMN reverse_state varchar(12) DEFAULT NULL,
  ADD COLUMN remote_error varchar(255) DEFAULT NULL,
  ADD COLUMN remote_tries int(11) NOT NULL DEFAULT 0,
  ADD COLUMN remote_at datetime DEFAULT NULL;
ALTER TABLE custom_orders ADD COLUMN frame_remote tinyint(1) DEFAULT NULL;
```

### 4. แพไม้: Cron Job ทุก 5 นาที (hPanel → Advanced → Cron Jobs)

```
php /home/<user>/domains/<โดเมนแพไม้>/public_html/api/cli/frame-remote-flush.php
```

หน้าเว็บที่เปิดอยู่ส่งรายการค้างให้เองทุกนาทีอยู่แล้ว ส่วน cron มีไว้สำหรับตอนที่ไม่มีใครเปิดเว็บ
